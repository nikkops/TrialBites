## Anything I found and fixed

The checklist caught four things. **`.gitignore` only covered `.env.local`**, through the Vite template's `*.local` rule, so a plain `.env` file would have been committed. I added `.env`, `.env.*` and `!.env.example`. **The scanner's Edge Function allowed calls from any website** (`Access-Control-Allow-Origin: *`); it now only answers the live app and localhost. **Food names and notes had no length limit in the database**, only in the form, so anyone with a login could have saved huge values by calling Supabase directly. `supabase/schema.sql` now has the limits, and `supabase/hardening.sql` adds them to the existing database. Finally, **a Gemini API key was exposed outside the repository during development**; Google suspended it, and it was replaced with a new, restricted key kept only in Supabase's secrets.

Not fixed yet, and listed as next steps: every commit's author email is a personal Gmail (row 27, a history rewrite); direct database connections are still open to any IP (row 14, Supabase's Network Restrictions setting); Supabase's minimum password length is lower than the app's 8 characters (row 23); and the unused Vite starter assets are still in the repository (row 30).
